Task 1 Safe JSON Parse
  • Write a function safeParse(str) using try/catch around JSON.parse(str).
  • If parsing succeeds, return the parsed object.
  • If parsing fails, log "Invalid JSON:" plus the error message and return null.
  • Test with '{"name":"Priya"}' and '{"name":"Priya"'.
