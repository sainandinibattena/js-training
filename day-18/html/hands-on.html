                    Task 3
                     Promise.all in Action
                

                

                    
    
                        
  • Write a function fetchPrice(item, ms) that returns a Promise resolving to a price object after ms milliseconds. Use this data: pen → 50, book → 200, bag → 800.
    • 
                        
  • Use Promise.all to fetch all three in parallel.
    • 
                        
  • Sum the prices and log the total.
    • 
                        
  • Time the whole thing with Date.now() — confirm it's near the SLOWEST item, not the sum.
